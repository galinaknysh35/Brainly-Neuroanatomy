# Brainly-Neuroanatomy
Brainly is an interactive 3D brain visualization tool designed for undergraduate neuroscience students. It uses the Harvard–Oxford Brain Atlas to help users learn neuroanatomy by exploring brain structures, their functions, and large-scale functional networks in an intuitive visual format.

Users can click on any brain structure to highlight it in 3D and instantly view a short, clear description of its function. Brainly also allows users to visualize functional networks (e.g., Default Mode Network) and see the anatomical structures that make them up, bridging the gap between structure and function.
